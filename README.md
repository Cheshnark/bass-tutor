# Bass Tutor

Profesor de bajo eléctrico en web/PWA: en español, offline y sin cuenta.
Lecciones cortas que siempre terminan tocando con metrónomo, con mástil interactivo y tablatura reproducible.

**Estado:** Fase 0 (pruebas de concepto de metrónomo y alphaTab). Ver [docs/project_state.md](docs/project_state.md).

```bash
npm install
npm run dev
```

Documentación en [`docs/`](docs/): negocio, arquitectura, decisiones, hoja de ruta e investigación previa.
